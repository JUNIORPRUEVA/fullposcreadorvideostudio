# Development

```bash
npm install
npm run prisma:generate
npm run db:push
npm run dev --workspace @fullpos-ad-studio/api
npm run dev --workspace @fullpos-ad-studio/web
```

Useful checks:

```bash
npm run prisma:validate
npm run db:push
npm run build
npm run typecheck
npm run test
npm run render:demo
npm run validate:video -- storage/renders/demo-fullpos-premium-vertical/final.mp4
```
